Testing an Acer laptop keyboard

This page uses the Windows laptop layout found on Acer Aspire, Swift, Nitro and Predator laptops. Tick Numeric keypad if yours has one. Press every key and check that each turns green.

What the colours mean

  • Green — the key sent a signal to your computer. It works.
  • Blue — the key is being held down right now. A key that stays blue after you let go is stuck.
  • Red outline — shown when you click “Highlight untested keys”: keys you have not pressed yet.
  • Dashed — Fn and Touch ID are handled inside the laptop and are never visible to any website. Test Fn through its shortcuts instead (Fn + brightness or volume).

Function keys not working on your Acer laptop?

On many Acer models the top row behaviour is set in the BIOS: restart, press F2, and on the Main tab look for an option such as Function key behavior or Hotkey Mode. Some newer models toggle it with Fn + Esc.

A key does not light up — what next?

  1. Rule out software first. Restart, then test again. Check that Filter Keys / Sticky Keys (Windows Settings → Accessibility → Keyboard) are off.
  2. Plug in a USB keyboard and test it here. If the external keyboard works, the laptop keyboard hardware is at fault, not Windows.
  3. Clean it. Turn the laptop off, tilt it, and blow compressed air under the dead key in short bursts. Crumbs and dust cause most “dead” or “sticky” keys.
  4. Reinstall the driver. Device Manager → Keyboards → right-click the keyboard → Uninstall device, then restart. Windows reinstalls it automatically.
  5. If one key or one whole row is still dead, the keyboard (or its ribbon cable) needs replacing. On most laptops the keyboard is a separate, inexpensive part.
