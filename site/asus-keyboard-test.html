How to use the ASUS Keyboard Test

  1. Tick Numeric keypad only if your ASUS has physical number keys
  2. Press every key except the power key in the top-right corner
  3. If only the hotkeys fail, reinstall the ASUS System Control Interface driver

Testing an ASUS laptop keyboard

This page uses the Windows laptop layout found on ASUS VivoBook, ZenBook, TUF Gaming and ROG laptops. Tick Numeric keypad if yours has physical number keys on the right.

Green means the key works, blue means it is held down, and dashed keys (Fn) can't be seen by any website. The full colour guide and the general step-by-step fixes for a dead key are on the laptop keyboard test page; this page covers what is specific to ASUS.

ASUS keys that behave differently

  • NumberPad in the touchpad. Some VivoBook and ZenBook models light up a number pad on the touchpad. That is a touchpad feature, so it won't show as keyboard keys here — check it by typing digits into any text box.
  • Function row. On many ASUS laptops Fn + Esc toggles Fn Lock. The same switch is in the MyASUS app under Customization → Function key lock.
  • Power key. Many VivoBook and ZenBook keyboards have the power button as the top-right key, sometimes with a fingerprint sensor. Don't press it during the test.
  • ROG and TUF extras. The Armoury Crate key and the volume or macro keys above the keyboard are handled by ASUS software, so they can stay grey even when they work.
  • Backlight. The brightness keys carry a keyboard-with-rays icon: F7 on many newer models, F3 / F4 on older ones, and Fn + the up and down arrows on some ROG and TUF laptops.

Hotkeys stopped working after a Windows update?

Brightness, volume and backlight keys on ASUS laptops depend on a driver called ASUS System Control Interface. If the letter keys pass this test but the hotkeys do nothing, update or reinstall that driver from MyASUS or from the support page for your exact model, then restart. MyASUS also has a System Diagnosis section for checking hardware.

Frequently asked questions

Why does my ASUS touchpad NumberPad not show up?

NumberPad is part of the touchpad, not the keyboard. Turn it on with the icon in the top corner of the touchpad and type digits into any text field to check it.

My ASUS hotkeys (brightness, volume, backlight) stopped working — why?

Those keys depend on the ASUS System Control Interface driver. Update or reinstall it from the MyASUS app or the support page for your model, then restart.

Will the Armoury Crate or ROG key light up in the test?

Usually not. That key is handled by ASUS software rather than sent as a normal key, so it can stay grey even when it works.
