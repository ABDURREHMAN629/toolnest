Discord Timestamps: How to Show a Time in Everyone's Time Zone

Quick answer: type <t:UNIX:F> in a Discord message, replacing UNIX with the time as a Unix timestamp in seconds — for example <t:1767225600:F>. Discord shows it in each reader's own time zone. The easiest way to get the code is a Discord timestamp generator.

"The event starts at 8 PM" means a different time in New York, London and Karachi. Discord timestamps fix that: instead of writing a time, you post a small code, and Discord displays it in every member's local time and date format. Here's how they work, every format available, and the quickest way to create one.

How Discord timestamps work

A Discord timestamp has three parts inside angle brackets:

<t:1767225600:F>

  • t: tells Discord this is a timestamp.
  • 1767225600 is a Unix timestamp — the number of seconds since 1 January 1970 (UTC). This one is 1 January 2026 at midnight UTC.
  • :F is the optional display style. If you leave it out, Discord uses style f.

Because a Unix timestamp marks one exact moment, Discord can convert it to anybody's local time — including daylight saving time — without you doing any time zone maths.

All Discord timestamp formats

Here is how <t:1767225600:STYLE> looks to a reader in New York with English (US) settings. Readers in other countries see their own local time and date format.

StyleCodeShows asGood for
Short time<t:1767225600:t>7:00 PMTimes on the same day
Long time<t:1767225600:T>7:00:00 PMWhen seconds matter
Short date<t:1767225600:d>12/31/2025Deadlines
Long date<t:1767225600:D>December 31, 2025Birthdays, release dates
Short date & time (default)<t:1767225600:f>December 31, 2025 7:00 PMMost announcements
Long date & time<t:1767225600:F>Wednesday, December 31, 2025 7:00 PMEvents and meetings
Relative<t:1767225600:R>"in 3 hours" or "2 months ago"Countdowns, "starts in…"

Notice that this reader sees December 31, 2025: midnight UTC on 1 January is still New Year's Eve in New York. That's exactly the kind of confusion timestamps prevent.

Tips for event announcements

  • Combine two styles. <t:1767225600:F> (<t:1767225600:R>) shows the full date and a live countdown, such as "Wednesday, December 31, 2025 7:00 PM (in 2 days)".
  • Use relative time for countdowns. The R style updates by itself, so "in 3 hours" becomes "in 2 hours" without editing the message.
  • Hover to check. On desktop, hovering over a timestamp shows the full date and time in a tooltip.
  • Planning across time zones? Use the Time Zone Converter to choose a time that suits most members before you announce it.

Common mistakes

  • Milliseconds instead of seconds. JavaScript's Date.now() and many tools give 13-digit milliseconds. Discord needs 10-digit seconds — divide by 1,000.
  • Wrong time zone when converting. If you convert "8 PM" as if it were UTC, everyone sees the wrong time. Always set the time zone the time is in.
  • Inside a code block. Text wrapped in backticks isn't formatted, so the code shows as plain text.
  • Typos in the format. Spaces, missing angle brackets or a lowercase/uppercase mix-up (f vs F) change or break the result.
  • Places that don't support message formatting — such as channel names — show the raw code instead of a date.

Timestamps for bot developers

Bots use exactly the same format in messages and embeds. In discord.py, discord.utils.format_dt(dt, style="F") builds the code from a datetime. In discord.js, the time(date, TimestampStyles.RelativeTime) helper does the same. You can also build the string yourself from a Unix timestamp in seconds.

Frequently asked questions

Do Discord timestamps show in everyone's time zone?

Yes. Discord converts the timestamp on each reader's device, using their own time zone and language settings, so everyone sees the correct local time.

What is the default Discord timestamp format?

If you leave out the style letter, as in <t:1767225600>, Discord uses the short date and time format (style f).

Why is my Discord timestamp showing the wrong year?

You probably used a timestamp in milliseconds (13 digits). Discord expects seconds (10 digits). Divide the number by 1,000, or create the code with a timestamp generator.

Can bots send Discord timestamps?

Yes. Bots can include timestamps in messages and embeds. discord.py has discord.utils.format_dt(), and discord.js has a time() helper with TimestampStyles.

Do Discord timestamps work on mobile?

Yes. Timestamps display in the desktop app, the web version and the mobile apps.
