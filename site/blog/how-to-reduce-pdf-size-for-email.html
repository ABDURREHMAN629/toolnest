How to Reduce PDF File Size for Email (Without Ruining Quality)

Quick answer: open a free PDF compressor, keep the Recommended level, and download the smaller file. Gmail allows 25 MB per email and Outlook about 20 MB; if the file is still too big, try the Strong level or split the PDF.

Big PDFs bounce back from email, fail to upload to job portals and take ages to open on phones. The good news: most large PDFs are large because of images, and those can usually be shrunk a lot with little visible difference.

Email attachment size limits

ServiceAttachment limit
Gmail25 MB (larger files become a Google Drive link)
Yahoo Mail25 MB
Outlook.com / Outlookabout 20 MB
Many job portals and formsoften 2–10 MB — check the page

Attachments grow by about a third when an email is sent, because of how they're encoded, so aim well below the limit — under 15 MB for Outlook, for example.

How to compress a PDF

  1. Open the Compress PDF tool and choose your file.
  2. Pick a compression level (see the table below). Recommended is the best balance for most documents.
  3. Optionally tick Convert images to grayscale for an even smaller file when colour doesn't matter.
  4. Download the compressed PDF and check it looks right.

Which compression level should you choose?

LevelWhat it doesBest for
LosslessCleans up and rewrites the file without touching image qualityText documents that only need a small reduction
RecommendedRe-compresses images and limits them to about 2,000 pixelsMost documents, reports and scans
StrongSmaller images (about 1,300 pixels) at lower qualityMeeting a strict size limit
ExtremeTurns every page into a compressed imageScanned documents when only the smallest file matters

Important: Extreme makes each page an image, so the text is no longer selectable or searchable, and fine print may look softer. Use it as a last resort. If a PDF is already well optimised, the tool tells you it couldn't make it noticeably smaller.

Why PDFs get so big

  • Scanned pages. Each scanned page is a full image. Scanning at 600 DPI in colour makes files enormous.
  • Photos pasted at full size. A photo from a phone camera can be several megabytes, even if it's shown small on the page.
  • Embedded fonts. Unusual fonts are stored inside the PDF so it looks the same everywhere.
  • Many pages. Long reports, especially with images on each page, add up.

Scanning documents? Make them small from the start

  • Scan text documents at 150–200 DPI — enough to read and print clearly.
  • Use grayscale or black-and-white unless colour matters.
  • Phone scanner apps (including the scanner in the iPhone Notes app and Google Drive on Android) usually create smaller files than a photo of the page.

Other ways to reduce PDF size

  • Mac Preview: File → Export → Quartz Filter → Reduce File Size. Quick, but it often reduces image quality a lot.
  • Adobe Acrobat: has a "Compress PDF" or "Reduce File Size" option; the full version is a paid product.
  • Microsoft Word: if you made the PDF from Word, use File → Save As → PDF and choose Minimum size (publishing online).

Still too big? Split it or send a link

If a long document is still over the limit, split the PDF into parts and send them in separate emails, or upload it to Google Drive, OneDrive or Dropbox and share a link. For forms that only accept images, convert pages with PDF to JPG.

Frequently asked questions

What is the maximum attachment size for email?

Gmail and Yahoo Mail allow attachments up to 25 MB per email; Outlook.com and most Outlook setups allow about 20 MB. Larger files are usually sent as a cloud link instead.

Will compressing a PDF reduce its quality?

The images inside can lose some sharpness, depending on the level you choose. Text and vector graphics stay sharp at the standard levels. The Extreme level turns each page into an image, so the text can no longer be selected or searched.

Why is my PDF so large?

Usually because of images: scanned pages, high-resolution photos or images pasted in at full size. Embedded fonts and many pages add to it too.

How do I reduce PDF size on a Mac?

Open the PDF in Preview, choose File → Export, and set Quartz Filter to "Reduce File Size". It can lower image quality a lot, so check the result.

How do I send a PDF that is still too big?

Split it into smaller parts with a PDF splitter, or upload it to Google Drive, OneDrive or Dropbox and email the share link instead.
