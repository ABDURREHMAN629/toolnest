How to Test a Laptop Keyboard (and Fix Keys That Stop Working)

Quick answer: open a free laptop keyboard test, pick your layout (Windows laptop, Lenovo ThinkPad or MacBook), and press every key. Working keys turn green. Keys that stay grey don't register, and keys flagged as "double-press" are sending two presses at once.

A key that doesn't work, types twice, or only works when you press hard is frustrating — especially on a laptop, where you can't simply swap the keyboard. Before you book a repair, test every key properly. It takes about a minute and tells you whether the problem is one key, several keys, or a software setting.

How to test your laptop keyboard online

  1. Open the Laptop Keyboard Test.
  2. Choose your layout: Windows laptop (Dell, HP, ASUS, Acer and most others), Lenovo ThinkPad / IdeaPad, or Apple MacBook. Tick UK / EU (ISO) if your Enter key is tall and you have a key between left Shift and Z. Turn on the number pad if your laptop has one.
  3. Press every key once, row by row. Tested keys turn green; keys you're holding turn blue.
  4. Click Highlight untested keys to spot any you missed — or any that didn't respond.

Reading the results

  • A key stays grey: the press isn't reaching the computer. Try it several times and with more force.
  • A key works only when pressed hard: often dirt under the key or a worn rubber dome.
  • "Double-press warnings" (key chatter): the tester flags keys that register twice within 25 milliseconds of being released — faster than a human can press. That's a sign of a failing switch, or dirt under the key.
  • Several keys in one row or area dead: usually a hardware fault, such as liquid damage or a loose keyboard cable.
  • Keys can't be pressed together: some keyboards can only register a limited number of keys at once. Check this with the keyboard ghosting test.

Dashed keys such as Fn and Touch ID are handled inside the laptop and can't be detected by any website. Test Fn by pressing it together with a media key (volume, brightness) and checking that the action happens.

Fixes for keys that don't work (Windows)

  1. Restart the laptop. It sounds obvious, but it clears many temporary driver glitches.
  2. Check Filter Keys and Sticky Keys. In Settings → Accessibility → Keyboard, turn off Filter Keys (which ignores quick or repeated presses) and Sticky Keys. Holding the right Shift key for 8 seconds can switch Filter Keys on by accident.
  3. Check Num Lock and Fn Lock. If number-pad keys don't type numbers, press Num Lock. If the top row changes volume instead of acting as F1–F12 (or the other way round), toggle Fn Lock — often Fn + Esc.
  4. Check the keyboard language. If keys type the wrong symbols (@ and " swapped, for example), go to Settings → Time & language → Language & region and make sure the keyboard layout matches your keyboard.
  5. Reinstall the keyboard driver. Open Device Manager, expand Keyboards, right-click your keyboard and choose Uninstall device, then restart. Windows reinstalls the driver automatically.
  6. Install updates. Run Windows Update and your laptop maker's update app (Dell, HP, Lenovo and ASUS all have one) for BIOS and driver fixes.

Quick hardware check: restart and enter the BIOS/UEFI setup (usually F2, F10, F12, Del or Esc at start-up). If the keys work there, the keyboard hardware is fine and the problem is in Windows.

Fixes on a MacBook

  • Check System Settings → Accessibility → Keyboard and turn off Slow Keys and Sticky Keys if they're on.
  • Check the input source in System Settings → Keyboard → Text Input if keys type the wrong characters.
  • For a sticky key, Apple's recommended cleaning method is to hold the laptop at a 75-degree angle and spray compressed air across the keys in a zig-zag, then repeat with the laptop turned to its right side and its left side.

Cleaning a sticky or unresponsive key

  1. Shut down the laptop and unplug it.
  2. Tilt it and use short bursts of compressed air around the problem key from several angles.
  3. For sticky residue, lightly dampen a cotton swab with isopropyl alcohol and clean around the key edges — never pour liquid onto the keyboard.
  4. Avoid prying keycaps off unless you know how your model's clips work; laptop keycaps break easily.

If you spilled a drink on the keyboard

Turn the laptop off immediately and unplug it. Turn it upside down in a tent shape so liquid drains out of the keyboard, wipe what you can, and leave it to dry for at least 24–48 hours before switching it on. Sugary drinks leave residue, so if keys are sticky or dead after drying, take it to a repair shop.

When to replace the keyboard

If several keys are still dead after these steps, the keyboard or its cable is faulty. Many laptop keyboards can be replaced by a repair shop; on some models the keyboard is part of the top case, which costs more. In the meantime, a USB or Bluetooth keyboard keeps you working — and you can test it with the same keyboard tester.

Frequently asked questions

How do I check if all my keyboard keys are working?

Open an online keyboard tester, choose your laptop layout and press every key once. Keys that turn green work. Use "Highlight untested keys" to see which ones you missed or which didn't respond.

Why can't the tester detect my Fn key?

The Fn key is handled inside the laptop itself and never sent to the browser, so no website can detect it on its own. Test it by pressing Fn together with another key, such as a brightness or volume key.

Why do some keys type the wrong symbols?

Usually the keyboard language or layout in your operating system doesn't match your physical keyboard — for example US vs UK. Change it in Windows Settings → Time & language, or on a Mac in System Settings → Keyboard.

Can I fix a laptop keyboard myself?

Software problems (settings, drivers, layout) are easy to fix yourself. A single sticky key can often be cleaned. If several keys are dead after a spill or a drop, the keyboard usually needs replacing by a repair shop.

Does the keyboard test work on a MacBook?

Yes. Choose the Apple MacBook layout. Most keys are detected; the Touch ID button and Fn/Globe key can't be seen by browsers.
