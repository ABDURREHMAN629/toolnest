About this tool

Check your monitor or phone screen for dead and stuck pixels with full-screen color tests. Dead Pixel Test is part of WebToolNest's collection of free web & device. It works instantly in your browser with no account and no installation.

Dead pixel test — full screen

Press Start full-screen test and your whole screen fills with one colour at a time: black, white, red, green, blue, gray, cyan, magenta and yellow. Click or press → for the next colour, ← to go back and Esc to exit. Look closely for dots that don't match. It's a dead pixel test full screen — a dead pixel tester that works on any device.

Dead, stuck or hot?

  • Dead pixel — always black; easiest to see on the white screen.
  • Stuck pixel — always one colour (red, green or blue); look on black and the other colours.
  • Hot pixel — always white; shows up on black.

Clean your screen first so dust isn't mistaken for a pixel.

Test and fix

As a dead pixel test and fix: stuck pixels can sometimes be revived by rapidly flashing colours over them for a few minutes, or by gently massaging the spot through a soft cloth (with the screen off). Truly dead pixels usually can't be fixed — check your warranty, as many brands replace screens with a set number of bad pixels.

Monitor, laptop, TV and Mac

As a dead pixel test monitor (a dead pixel test for monitor and dead pixel test for laptop), test a new display within the return window. A dead pixel test for mac works in Safari or Chrome. For a dead pixel test for tv, open this page in the TV's browser or connect a laptop by HDMI.

Phone, iPhone, Android and iPad

It works as a dead pixel test phone (or dead pixel test for phone, dead pixel test for mobile) check on Android — a dead pixel test android and dead pixel test samsung check — and as a dead pixel test for ipad. As a dead pixel test iphone (dead pixel test for iphone), note that Safari on iPhone doesn't allow true full screen, so the colour fills the browser window — scroll to hide the bars and check the edges separately.

OLED screens

As a dead pixel test oled (dead pixel test for oled), the gray screen is also good for spotting burn-in — faint ghost images of keyboards or status bars.

A dead pixel test for camera sensors is different: take a photo with the lens cap on and look for bright dots. A simple dead pixel test.
