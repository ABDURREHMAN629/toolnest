How to use the Dell Keyboard Test

  1. Tick Numeric keypad if your Dell has one
  2. Press every key, holding Fn for F1–F12 if the top row is in multimedia mode
  3. Compare any grey keys with the Dell F12 Diagnostics result

Testing a Dell laptop keyboard

This page is set to the Windows laptop layout used by most Dell Inspiron, Vostro, Latitude, XPS and G-series laptops. If your Dell has a number pad (most 15.6″ and larger models), tick Numeric keypad. Press every key from Esc to the right arrow and check that each one turns green.

Green means the key works, blue means it is held down, and dashed keys (Fn) can't be seen by any website. The full colour guide and the general step-by-step fixes for a dead key are on the laptop keyboard test page; this page covers what is specific to Dell.

Dell keys that behave differently

  • Top row. Dell ships most laptops with the top row in multimedia mode, so F1–F12 may not light up until you hold Fn or switch Fn Lock with Fn + Esc. To change it permanently, restart, press F2 for the BIOS setup and look for Function Key Behavior.
  • Keyboard backlight. It is the key with the glowing-keyboard icon — F5 on many recent Inspiron and XPS models, F10 or F6 on others, sometimes with Fn. The backlight changes inside the laptop, so that press may not light up here.
  • Compact models. On small Dells such as the XPS 13, Home, End, PgUp and PgDn share keys with the arrows or the F-row and need Fn. Test them as a combination.
  • Latitude pointing stick. The small stick between G, H and B and the extra buttons below the space bar are mouse controls. They will not show up in a keyboard test.

Run Dell's own keyboard diagnostic

  1. Before Windows starts: restart and tap F12 at the Dell logo, then choose Diagnostics. This pre-boot test (ePSA / SupportAssist Pre-Boot) checks the keyboard without any drivers, so a failure there is a hardware fault.
  2. Inside Windows: open the SupportAssist app, go to Troubleshooting, choose to check a specific piece of hardware and pick Keyboard.
  3. Note any error code. If the laptop is under warranty, Dell support will ask for it together with the Service Tag printed on the bottom of the laptop.

If keys fail on your Dell

  • A few keys dead after a spill or crumbs: clean first, then re-test here. One dead key is usually dirt; a whole row or column is usually the keyboard matrix or its ribbon cable.
  • Keys or touchpad feel raised: stop and have the battery checked. A swollen battery under the palm rest can push the keyboard up on thin laptops.
  • Replacement: on many Inspiron, Vostro and Latitude models the keyboard is a separate part. On thin models such as the XPS line it is built into the palm-rest assembly, so the repair costs more.

Frequently asked questions

How do I run the Dell keyboard diagnostic?

Restart the laptop and tap F12 at the Dell logo, then choose Diagnostics. The built-in pre-boot test checks the keyboard without Windows. Inside Windows, the SupportAssist app can also scan the keyboard on its own.

Why do my Dell function keys change volume instead of F1–F12?

The top row is in multimedia mode. Press Fn + Esc to toggle Fn Lock, or set Function Key Behavior in the BIOS setup (F2 at startup).

How do I turn on the keyboard backlight on a Dell?

Look for the key with the illuminated-keyboard icon — F5 on many recent Inspiron and XPS models, F10 or F6 on others, sometimes together with Fn. Not every Dell has a backlit keyboard.
