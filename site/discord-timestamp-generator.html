How Discord timestamps work

If you type “game night at 8 PM” in a Discord server, everyone reads it in their own time zone and half of them show up at the wrong time. A Discord timestamp fixes that. You paste a short code like <t:1792540800:F>, and Discord shows each reader the time converted to their time zone and language. The number is a Unix timestamp — the seconds since 1 January 1970 UTC.

The 7 styles

  • :t short time (8:00 PM) and :T long time (8:00:00 PM)
  • :d short date (10/20/2026) and :D long date (October 20, 2026)
  • :f date and time — the default if you leave the style out
  • :F full date with weekday and time
  • :R relative time (“in 3 hours”, “2 days ago”), which keeps updating in Discord — perfect for countdowns

Tips

  • Pick the time zone the event is planned in — for example New York for a US-hosted tournament — and the tool converts it correctly, including daylight saving time.
  • Combine styles: “Starts <t:…:F> (<t:…:R>)” shows both the date and a live countdown.
  • Timestamps work in messages, embeds, channel topics, event descriptions and bot replies.
