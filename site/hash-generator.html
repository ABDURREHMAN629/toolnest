About this tool

Generate MD5, SHA-1, SHA-256, SHA-384 and SHA-512 hashes from text or files, and verify checksums. Hash Generator is part of WebToolNest's collection of free developer tools. It works instantly in your browser with no account and no installation.

Hash generator — MD5, SHA-1, SHA-256, SHA-512

Type or paste text and see its MD5, SHA-1, SHA-256, SHA-384 and SHA-512 hashes instantly, or drop a file to get its checksums. Paste an expected hash in “Verify” and a ✓ appears next to the matching algorithm. It's a hash generator online — a hash generator sha256 (an hash generator online sha256), hash generator sha512 and hash generator md5 (or hash generator online md5) in one.

Examples

For the text “hello world”: MD5 = 5eb63bbbe01eeed093cb22bb8f5acdc3; SHA-256 = b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2efcde9. Change one letter and the hash changes completely. A hash only goes one way — there's no hash generator to text that reverses it.

Verify a download (file checksum)

As a hash generator for file checks (an md5 hash generator for file), drop the file you downloaded, paste the checksum from the publisher's site, and look for the ✓. On Windows (a hash generator for windows without installing anything), you can also run Get-FileHash file.iso in PowerShell or certutil -hashfile file.iso SHA256. No hash generator download is needed.

Passwords, salt and keys

As a hash generator for password (or hash generator password) storage, plain MD5 or SHA hashes aren't safe — attackers can test billions per second. Real systems use a slow, salted algorithm such as bcrypt or Argon2. A hash generator with salt here means adding the salt to the text yourself; a hash generator with key (HMAC) isn't included.

In Python

A hash generator in python: hashlib.sha256("text".encode()).hexdigest() — the same as a hash generator from string here. (Looking for a hash generator for youtube? That's usually a hashtag generator — a different tool.) A simple hash generator.
