How to use the HP Keyboard Test

  1. Tick Numeric keypad if your HP has one
  2. Press every key, including the Home / PgUp / PgDn / End column, but skip the power key
  3. Confirm grey keys with HP PC Hardware Diagnostics (Esc, then F2)

Testing an HP laptop keyboard

This page uses the Windows laptop layout found on HP Pavilion, Victus, Envy, Omen, ProBook and EliteBook laptops. Tick Numeric keypad if your HP has one. Work across each row and make sure every key turns green.

Green means the key works, blue means it is held down, and dashed keys (Fn) can't be seen by any website. The full colour guide and the general step-by-step fixes for a dead key are on the laptop keyboard test page; this page covers what is specific to HP.

HP keys that behave differently

  • Action keys. HP ships the top row as action keys (brightness, volume, playback). F1–F12 only register here while you hold Fn, unless you turn off Action Keys Mode: restart, press F10 for the BIOS, open System Configuration.
  • Fn Lock on business models. On many ProBook and EliteBook keyboards Fn + left Shift toggles Fn Lock without entering the BIOS.
  • Power key in the top row. Many Envy, Spectre and Pavilion models have the power button as a keyboard key at the top right. Skip it — pressing it puts the laptop to sleep.
  • Extra column on the right. 14″ and 15″ HPs often have Home, PgUp, PgDn and End in a column beside Enter and Backspace. They are easy to miss, so use Highlight untested keys at the end.
  • Fingerprint reader. On newer models it sits where right Ctrl used to be. It is not a key and will not light up.

Run HP's keyboard test

  1. Restart and press Esc repeatedly until the startup menu appears.
  2. Press F2 for HP PC Hardware Diagnostics UEFI.
  3. Choose Component Tests → Keyboard and follow the prompts. Because this runs outside Windows, a failure here confirms a hardware fault before you contact HP support.

If the whole HP keyboard stops responding

Try a power reset first: shut down, unplug the charger and all USB devices, hold the power button for about 15 seconds, then start up and test again. If keys still fail both here and in the UEFI test, the keyboard needs service. On many HP consumer laptops the keyboard is fixed into the top cover, so it is replaced together with the palm rest.

Frequently asked questions

How do I test my HP keyboard outside Windows?

Restart, press Esc repeatedly until the startup menu appears, then press F2 for HP PC Hardware Diagnostics UEFI. Choose Component Tests and then Keyboard.

What is Action Keys Mode on an HP laptop?

It makes the top row control brightness, volume and playback without holding Fn. Turn it off in the BIOS (F10 at startup → System Configuration) if you want plain F1–F12.

My HP keyboard stopped working completely — what should I try first?

Do a power reset: shut down, unplug the charger and any USB devices, hold the power button for about 15 seconds, then start again and re-test here.
