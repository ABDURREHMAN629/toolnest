HTML encoder and decoder

Paste text and click Encode HTML to escape the five special characters — & → &amp;, < → &lt;, > → &gt;, " → &quot; and ' → &#39; — or Decode HTML to turn entities back into plain text. Tick “Also encode non-ASCII characters” to write © or emoji as numeric entities like &#169;. It's an html encoder decoder online: an html encode online and html decode online tool, and an html entity encoder online.

What are HTML entities?

what are html entities? They're codes that display a character the browser would otherwise treat as markup, or that's hard to type. A few from the html entities list:

  • html encoded ampersand: &amp; · less than &lt; · greater than &gt;
  • html escape single quote: &#39; (or &apos;) · double quote &quot;
  • html encode space that won't break: &nbsp; · © &copy; · ™ &trade; · → &rarr;

Escape HTML to prevent XSS

The main reason to html escape text: if user input is shown on a page without escaping, someone can inject scripts. Always escape html to prevent xss when inserting text into HTML — the html escape characters above are exactly the ones that matter. This page is handy for checking output and preparing snippets, such as showing code on a blog.

  • html encode in c# — WebUtility.HtmlEncode() / HtmlDecode().
