What is keyboard ghosting?

Most keyboards don't wire every key separately. They use a grid, and when you hold certain combinations the keyboard can't tell which keys are down — so it drops some presses. That is ghosting (sometimes called blocking or jamming). In games it means a jump or reload that never happens while you are running diagonally.

How to test it

  1. Hold the keys you use together in games — for example W + A + Shift, then add Space.
  2. Every held key should turn blue and the Held at once counter should rise with each one.
  3. If a key stays grey while the others are held, that combination ghosts. Try other combinations — rollover limits depend on which keys share the grid.

What the numbers mean

  • 2–3 keys: typical for basic office keyboards. Fine for typing, limiting for games.
  • 6 keys: “6-key rollover”, the limit of standard USB keyboards — enough for nearly every game.
  • More than 6: “N-key rollover” (NKRO) — every key is read independently. Some keyboards only enable NKRO in their software or with a key combination.

Note: some laptops and browsers cap the count themselves, and macOS reports keys differently while command is held, so test with letters, Shift and Space for the clearest result.
