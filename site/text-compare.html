About this tool

Compare two texts and highlight the differences line by line and word by word. Text Compare (Diff Checker) is part of WebToolNest's collection of free text tools. It works instantly in your browser with no account and no installation.

Text compare — find the differences

Paste the original text on the left and the changed text on the right, then click Compare. Every line is lined up: removed lines turn red, added lines green, and changed lines yellow with the exact words that changed highlighted. A summary counts the added, removed and modified lines. Options let you ignore case and extra spaces. It's a text compare online tool — text compare online free and private, because nothing is uploaded.

For code, documents and contracts

  • text compare for code — compare two versions of a config file, script or JSON (format JSON first with the JSON Formatter so lines match up).
  • text compare for differences between two drafts of an essay, contract or policy — see exactly which words an editor changed.
  • text compare for large files — it handles a few thousand lines in the browser; split very long files into sections.

Similarity and plagiarism

To compare text for similarity, paste both and look at how many lines are unchanged. It isn't a text compare for plagiarism checker that searches the web — it compares exactly the two texts you give it.

Comparing two lists of followers? A text compare for instagram followers (or text compare for instagram) check works with the lists one name per line — but the Instagram Unfollowers Tracker reads your official Instagram data export and shows who doesn't follow you back automatically.

Windows, Mac, Notepad++ and VS Code

It runs in any browser, so it's a text compare tool for windows (a text compare for windows) and a text compare for mac with nothing to install — a text compare for free alternative to desktop apps. If you prefer an editor:

  • text compare in notepad++ — install the “Compare” plugin from Plugins Admin.
  • text compare in vs code — select two files in Explorer, right-click and choose “Compare Selected”.
  • text compare excel — =EXACT(A1,B1) tells you whether two cells match exactly.
