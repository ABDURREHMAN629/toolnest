Simple online to-do list

Type a task and press Enter to add it. Tick tasks off as you finish them, click any task to edit it, and delete with ✕. Filter by All, Active or Completed, and clear finished tasks in one click. A counter shows how many are left. Your list is saved automatically in this browser, so it's there when you come back — a free to-do list app without an account.

To-do list for today

A to-do list for today works best when it's short: pick three must-do tasks, then add smaller ones. Start with the hardest task while your energy is highest, and break big jobs into steps you can finish in under an hour.

To-do list for ADHD adults

As a to-do list for adhd adults, keep it visible and small: write tasks as actions (“email Sara about rent”, not “rent”), check off even tiny wins, and pair it with the Pomodoro Timer to start. Clearing completed tasks keeps the list from feeling overwhelming.

For students, school and kids

  • to-do list for students (a to-do list for students free option) — homework, revision topics and deadlines, oldest due first.
  • to-do list for school — one task per subject, ticked off after each study session.
  • to-do list for kids — morning routine and chores; ticking boxes is motivating.

Template and format

A good to-do list format: one action per line, starting with a verb, with a deadline if it has one. This page is a ready-made to-do list template. If you prefer files, a to-do list template excel needs just three columns — Task, Due date, Done (a checkbox) — and a to-do list template word is a bulleted checklist. List to-do list items like “Pay electricity bill” rather than vague goals.
