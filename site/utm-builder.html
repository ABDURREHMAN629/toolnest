UTM links explained

utm links explained: UTM parameters are labels added to a link so Google Analytics knows where a visitor came from. The utm link meaning of each part:

  • utm_source — who sent the traffic (facebook, newsletter, google).
  • utm_medium — the type (social, email, cpc).
  • utm_campaign — your campaign name (summer_sale).
  • utm_term, utm_content, utm_id — keyword, ad variation and campaign ID.

utm examples — the utm code format: https://example.com/landing-page?utm_source=facebook&utm_medium=social&utm_campaign=summer_sale.

How to build UTM links

how to build utm links (or create utm link tags): use one naming style and stick to it, keep everything lowercase, and never put UTMs on links within your own site — they restart the visit. is utm free? Yes — UTM tags cost nothing; this utm builder online (utm builder tool) just writes them.
